Table to CSV & XLSX — FocusPlus finds the tables on the page you are already looking at and writes them out as CSV, XLSX, JSON or Markdown. It runs entirely inside your browser.

Download & install — free 355 KB · Chrome 102 and newer · Edge and Brave work too

What it does

  • Scans the current page and lists every table it finds, with its true size.
  • Click-to-select picker — press Alt+Shift+T, hover, click the table you want.
  • Clean before you export: delimiter, trim, header row, column selection, blank-row stripping.
  • CSV with a UTF-8 BOM and CRLF line endings, so Excel opens it without an import wizard.
  • XLSX written off-thread in a worker, so the popup never freezes on a large table.
  • Leading zeros stay leading zeros. 004512 does not become 4512.
  • Cells that begin with =, +, - or @ are neutralised, so a scraped formula cannot execute when the file opens.
  • Merged cells, rowspan="0", nested tables, ARIA grids, CSS grids, shadow DOM and same-origin frames all handled.

Four permissions. That is the whole list.

This is the difference you see on the install screen. Chrome shows a warning for every permission an extension asks for, and the widest one is "Read and change all your data on all websites" — the warning that <all_urls> produces. This extension does not request it, and there is no host_permissions key in its manifest at all.

PermissionWhy it is neededWhat it cannot do
activeTab Read the page you invoked the extension on, and only that page, and only after you click. It cannot follow you to another site, and it is revoked the moment you navigate away.
storage Remember your cleaning preferences and, if you leave the box ticked, your last scan. It cannot sync anywhere. Everything stays in this browser profile.
scripting Inject the extraction code into the tab you just activated. It cannot inject into a tab you have not activated.
contextMenus Add the right-click "Export table to CSV" and "Pick a table" entries. It cannot read anything on its own.

About the 500-row limit. Each table exports its first 500 rows, and the header counts as one of them. The popup always shows the table's real size next to a 500 max badge, so nothing is hidden from you before you click export. There is no time limit, no daily quota, no account, and no way to buy your way past it — because there is nothing to buy. The limit is a fixed property of this free build.

What it cannot reach

Some tables are structurally out of reach for any extension working under these permissions. They are listed on the disclaimer page: chrome:// pages, tables painted into <canvas>, cross-origin iframes, and closed shadow roots. If a page renders its data on a canvas, there is no table element to read.

Privacy, in one paragraph

No network requests. No telemetry. No analytics. No account. No host permissions. Table contents are read into memory, written to a file you asked for, and discarded. The only things stored are your cleaning preferences and optionally your last scan, both in chrome.storage.local on this device. Read the full privacy policy.
