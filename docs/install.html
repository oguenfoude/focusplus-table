Install it in five steps.

Version 1.0.0 · Windows, macOS, Linux · Chrome 102 or newer, Edge, Brave

Download v1.0.0 (.zip, 355 KB) Release notes
This is a direct install, not the Chrome Web Store. Nothing is signed by Google and nothing updates itself — you are loading the exact folder you downloaded. That is also why it keeps working offline forever.

The five steps

  1. Download the zip. Click the button above. It saves focusplus-table-1.0.0-release.zip to your Downloads folder. On Windows, if SmartScreen offers to keep or discard the file, choose Keep. It is an unsigned zip archive, not an installer, and it cannot run anything on its own.
  2. Unzip it somewhere permanent. Right-click → Extract All on Windows, or double-click on macOS. Put the folder somewhere you will not delete by accident, for example C:\Users\<you>\FocusPlusTable or ~/FocusPlusTable.
    The folder you want is the one that contains manifest.json directly inside it — if you see another folder nested inside, go one level deeper.
  3. Open the extensions page. Type chrome://extensions into the address bar and press Enter. On Edge use edge://extensions, on Brave brave://extensions.
  4. Turn on Developer mode. The toggle sits in the top-right corner of that page. Without it, the Load unpacked button does not appear.
  5. Click “Load unpacked” and pick the folder. Select the folder from step 2. The FocusPlus Table card appears, and the toolbar icon is pinned automatically. If you do not see the icon, click the puzzle-piece button in the toolbar and pin Table to CSV & XLSX — FocusPlus.

Check it works

Open any page with a table — for example a Wikipedia article with a results table — then click the toolbar icon. You should see a card per table with its real size. Click CSV and the file lands in your Downloads folder.

The fastest proof is a big one: scan a page with a long table and the card will read something like 1,001 × 4 with a 500 max badge, and the status line afterwards will say first 500 of 1,001 rows. That is the cap being honest, not a bug.

Updating

Download the newer zip, unzip it over the same folder, then click the circular reload arrow on the extension card in chrome://extensions. Your cleaning preferences and last scan survive, because they live in the browser profile, not in the folder.

Uninstalling

Click Remove on the extension card, then delete the folder. Removing the extension deletes all four local storage keys with it. There is nothing on any server to clean up, because nothing was ever sent.

If something goes wrong

SymptomCause and fix
“Load unpacked” is missing Developer mode is off. Toggle it in the top-right of chrome://extensions.
“Manifest file is missing or unreadable” You selected the outer folder. Go one level down, until manifest.json is visible in the file list.
The popup says “Scan failed” The page may be a protected origin (chrome://, the Chrome Web Store, a PDF viewer). Those cannot be scripted by any extension.
No tables found on a page that clearly has one The table may be drawn into a canvas, or live inside a cross-origin iframe. Both are out of reach by design — see the disclaimer.
Chrome shows “Disable developer mode extensions” A Chrome startup nag about any unpacked extension. Click Cancel; it does not affect this one.
