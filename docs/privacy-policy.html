Privacy Policy

Table to CSV & XLSX — FocusPlus · version 1.0.0 · last updated 24 November 2026

This extension makes zero network requests. It has zero host permissions. No table content, page address, or usage data ever leaves your device, because there is no code in the package that can send it anywhere.

1. Who is responsible

The extension is published under the name FocusPlus. For any privacy question, write to oguenfoude@proton.me.

2. What is collected

Nothing is collected. Specifically, the extension does not collect:

  • the pages you visit or their addresses;
  • the contents of any table you export;
  • your identity, email address, or any account information;
  • crash reports, diagnostics, or usage statistics;
  • an advertising or analytics identifier of any kind.

There is no account system, no sign-in, no licence key, and no payment of any kind in this version. Nothing is sold, and no data is shared with anyone, because no data is gathered in the first place.

3. What is stored, and exactly where

The extension uses chrome.storage.local, which is a private store on your own device inside your browser profile. It is not synced to any server and is not visible to any website. Four keys exist in total:

KeyContentsWhen it is written
ttc_remember A single boolean: whether the "Remember last scan" box is ticked. When you change that checkbox.
ttc_last_scan The list of detected tables for the page you last scanned — table identifiers, row and column counts, a short header preview, the tab identifier and the page address — plus the time of the scan. Written only while "Remember last scan" is ticked, and deleted the moment you untick it. After a successful scan.
fp_clean Your cleaning preferences: CSV delimiter, and the trim / strip-empty / header / safety toggles. When you change a cleaning control.
fp_pick The table you last selected with the click-to-select picker, already capped to 500 rows, so the popup can offer it again. Expires automatically after ten minutes and is cleared when you press "Dismiss". When you pick a table.

There are no other storage keys. Uninstalling the extension deletes all of them.

4. Network activity

None. The manifest declares no host_permissions, so the extension could not reach a remote server even if it tried. It includes no analytics library, no crash reporter, no update ping, and no remote code. Every file it executes is inside the installed package.

If you click a link in this policy or in the extension's footer — for example the support address — your browser opens that page normally. That navigation is your browser's, not the extension's, and is the only way any data leaves your machine.

5. Permissions, and why each one exists

PermissionPurpose
activeTabRead the page you explicitly invoked the extension on. Temporary, and revoked when you navigate away.
storageHold the four keys listed in section 3, locally.
scriptingInject the extraction code into the tab you activated.
contextMenusAdd the right-click export and pick entries.

<all_urls> is not requested. The extension cannot read a page you did not activate, and it cannot read a chrome:// page at all.

6. Your control over the data

  • Untick "Remember last scan" in the popup to delete ttc_last_scan immediately.
  • Press "Dismiss" on a picked table to delete fp_pick.
  • Removing the extension deletes every key.
  • Clearing your browser profile data removes them as well.

7. Children

The extension is a general-purpose file-formatting tool. It is not directed at children, and it collects no personal information from anyone, of any age.

8. Legal basis and your rights

Because no personal data is processed on any server, there is no data controller holding your information and no transfer to a third country. Where data-protection law grants you rights of access, rectification, erasure, restriction, portability or objection, they are satisfied trivially: the only data that exists is on your device, under your control, and uninstalling removes it. You can still write to oguenfoude@proton.me with any question.

9. Changes to this policy

If a future version ever adds a network feature, this page will be updated before that version ships, and the change will be described in the extension's release notes. A version that contacts a server would require a new permission, which Chrome shows you on update and which you can decline.

Short version. No network. No host permissions. No account. No telemetry. Four local storage keys, listed above by name. Contact oguenfoude@proton.me.
